# Разработка и проверка

Основная работа ведётся от ветки `develop` в тематических ветках `feature/*`. В `master` попадает только проверенный результат через релизную ветку.

Сообщения коммитов следуют Conventional Commits и описывают изменение по-русски, например `feat: добавить пагинацию списка постов`.

Перед объединением ветки должны проходить форматирование, линтер, проверка типов, тесты и production-сборка.
