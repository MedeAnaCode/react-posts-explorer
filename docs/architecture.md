# Архитектура приложения Список постов

Приложение строится как одностраничный клиент на React и TypeScript. Браузер получает данные напрямую из JSONPlaceholder, поэтому отдельный backend и база данных для требований задания не нужны.

Production-сборка представляет собой статические файлы. Их раздаёт Nginx в Docker-контейнере с возвратом `index.html` для клиентских маршрутов.

Подробное описание модулей и потока данных будет дополнено вместе с реализацией.
