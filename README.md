# Список постов

Показательное тестовое задание на React и TypeScript. Приложение получает посты из открытого API, поддерживает постраничный просмотр и открывает отдельную страницу каждого поста.

## Статус

Репозиторий инициализирован. Рабочая версия приложения разрабатывается в ветке `develop`, проверенные релизы попадают в `master`.

## Исходное задание

Оригинал задания сохранён в каталоге `docs/materials` под осмысленным именем. Реализация дополняет обязательные требования тестами, контейнерной сборкой и документацией для публикации.

## Ветки

- `master` — проверенные релизы.
- `develop` — интеграция готовых функций.
- `feature/*` — изолированная разработка отдельных частей.
- `release/*` — финальная стабилизация версии.
